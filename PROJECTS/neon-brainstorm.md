# Neon Brainstorm Dialect

Example project-local dialect for a collaborative game-idea garden.

## Common Modes

- `web_safe`: web app, auth, data flow, AI routes
- `game_idea`: seed-to-prototype ideation

## Terms

- `seed`: submitted game idea unit
- `spark`: brainstorm note or reaction
- `quick proto`: fast playable prototype generation
- `full`: fuller game generation path
- `asset`: user-contributed creative file such as image or audio
