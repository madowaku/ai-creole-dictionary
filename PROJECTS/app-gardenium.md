# App Gardenium Dialect

Example project-local dialect for an app-idea community and growth-agent workflow.

## Common Modes

- `web_safe`: Firebase, Stripe, AI routes, auth/data flow
- `codex_patch`: small repo changes and docs updates

## Terms

- `Growth Agent`: idea diagnosis, MVP planning, tester strategy, and suggestion workflow
- `idea`: user-submitted app idea
- `salon`: community discussion area
- `membership`: billing and access feature area
- `compact_receipt`: final response with changed files, checks, and remaining manual check

## Output Convention

```text
OUT: compact_receipt
- changed files
- checks
- remaining manual check
```
