# Project Dialects

This folder tracks reusable notes about project-local AI Creole dialects.

Project-specific terms should usually live first in that project's own `AI_CREOLE.md`.

Promote terms or modes here only when they are useful as examples or when a project needs a shared public reference.

Do not force every project into one global glossary.

## Shared references

- `3d/3D_PROMPT_PATTERNS.md`: reusable 3D production patterns, templates, and candidate dialect terms while keeping the universal Core unchanged.
