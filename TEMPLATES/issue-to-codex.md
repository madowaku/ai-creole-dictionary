# Issue To Codex

Use when converting an issue or vague request into a small Codex task.

```text
ROLE: Codex
MODE: codex_patch

TASK:
Turn this issue into a small patch.

GOAL:

STATE:

INPUT:

TARGET:

DO:
- inspect existing files first
- implement the smallest useful fix
- preserve existing behavior outside the issue

KEEP:

NO:
- no broad refactor
- no unrelated cleanup

OUT:
- changed files
- checks run
- remaining risk

CHECK:

RISK:

NEXT:
```
