# Project Glossary Update

Use when adding a repeated local term or mode to a project's `AI_CREOLE.md`.

```text
ROLE: Codex
MODE: codex_patch

TASK:
Update the project-local AI Creole glossary.

GOAL:
Reduce future handoff ambiguity without growing the glossary too much.

STATE:

TARGET:
AI_CREOLE.md

DO:
- read existing terms first
- add only terms already useful in project work
- keep definitions short

KEEP:
- existing term meanings
- project-local dialect style

NO:
- do not redefine existing terms silently
- do not promote project-only terms to global dictionary

OUT:
- changed terms
- changed files

CHECK:
- no duplicate term
- no global/core change needed

RISK:

NEXT:
```
