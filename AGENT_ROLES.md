# Agent Roles

Common `ROLE` values for AI Creole prompts.

## ROLE: Codex

Use for codebase inspection, patching, repo updates, tests, and file-based work.

## ROLE: Local LLM

Use for short local review, classification, risk checks, glossary checks, and offline reading of project markdown.

## ROLE: ChatGPT

Use for broader explanation, ideation, summary, translation, and cross-source reasoning when given the Google Drive summary or GitHub source.

## ROLE: Human

Use for decisions, approval, product taste, project intent, and constraints that cannot be inferred safely.
